## 2024-05-18 - Missing Authentication on Admin Endpoints in Notifications API
**Vulnerability:** The `create_alert` and `get_notification_stats` endpoints in `app/api/notifications_api.py` were missing the `require_admin_key` dependency, exposing admin functionality to unauthenticated users.
**Learning:** Even when the docstring or memory states an endpoint is restricted to administrators using a decorator, it's essential to verify its presence in the actual route definition. Missing decorators lead to immediate access control bypasses.
**Prevention:** Always verify the presence of `dependencies=[Depends(require_admin_key)]` on new or modified endpoints meant for administrators. Incorporate automated security tests to specifically query admin endpoints without authentication headers and assert they return 401/403.
## 2024-05-24 - Missing Authorization on Admin Endpoints in Performance API
**Vulnerability:** The `/cache/preload` and `/cache/stats` endpoints in `app/api/performance_api.py` were intended for admins but were lacking the `dependencies=[Depends(require_admin_key)]` check, making them publicly accessible.
**Learning:** Even if an endpoint is described as "admin only" in comments or docstrings, if the authorization dependency decorator is missing on the actual route definition, it will not be enforced. FastAPI dependencies are required per-route or per-router.
**Prevention:** When reviewing endpoints, especially those dealing with cache management or system configurations, always verify that the access control decorators explicitly exist on the route definition and don't assume they are inherited or magically applied based on comments.
