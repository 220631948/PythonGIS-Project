## 2024-05-18 - Missing Authentication on Admin Endpoints in Notifications API
**Vulnerability:** The `create_alert` and `get_notification_stats` endpoints in `app/api/notifications_api.py` were missing the `require_admin_key` dependency, exposing admin functionality to unauthenticated users.
**Learning:** Even when the docstring or memory states an endpoint is restricted to administrators using a decorator, it's essential to verify its presence in the actual route definition. Missing decorators lead to immediate access control bypasses.
**Prevention:** Always verify the presence of `dependencies=[Depends(require_admin_key)]` on new or modified endpoints meant for administrators. Incorporate automated security tests to specifically query admin endpoints without authentication headers and assert they return 401/403.
## 2024-05-24 - Missing Authentication on Administrative API Endpoints
**Vulnerability:** The `/cache/preload` and `/cache/stats` endpoints in `app/api/performance_api.py` were missing authentication, allowing unauthorized users to trigger cache preloading (potential Denial of Service) and view sensitive cache statistics.
**Learning:** Endpoints intended for administrators must explicitly include `dependencies=[Depends(require_admin_key)]` in their FastAPI router decorators to prevent unauthorized access, as the dependency itself functions correctly only when applied.
**Prevention:** When creating or auditing new API endpoints, especially those under administrative categories like "performance" or "cache management", verify that the appropriate access control decorators (like `require_admin_key`) mentioned in docstrings or documentation are explicitly applied to the route definitions.
