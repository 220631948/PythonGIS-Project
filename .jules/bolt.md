## 2026-03-09 - [Backend] Double Serialization Avoidance in Paginated GeoJSON Responses
**Learning:** Returning paginated GeoDataFrames by calling `json.loads(gdf.to_json())` inside a dictionary, and then returning it with `JSONResponse` causes redundant `String -> Dict -> String` serialization. Additionally, doing the same for offline packages leads to performance and memory overhead when dealing with large datasets.
**Action:** Use the `create_geojson_response` utility or string interpolation directly to splice the pre-serialized GeoJSON string from `gdf.to_json()` with metadata JSON. This avoids intermediate dictionary representation and relies on FastAPI's raw `Response`.
