## 2026-03-14 - [Backend] Prevent Event Loop Blocking in FastAPI Async Endpoints
**Learning:** Calling synchronous, I/O-heavy or CPU-bound functions like `geopandas.read_file()` or `requests.get()` directly within `async def` FastAPI endpoints will block the asyncio event loop, causing severe latency degradation under load. This was happening heavily with `data_loader.get_gdf(dataset_name)`.
**Action:** Always wrap legacy synchronous blocking operations in `asyncio.to_thread` when executing them within async functions. Created `async def get_gdf_async(...)` in `DataLoader` to handle this explicitly for data fetching, and refactored API endpoints to use it via `await data_loader.get_gdf_async(...)`.
