## $(date +%Y-%m-%d) - Interactive Custom UI Components Rely Extensively on Mouse Events
**Learning:** Found that custom interactive components acting as buttons (e.g., collapsible panel headers in `RoutePanel.tsx`) frequently rely solely on `onClick` handlers and lack the necessary keyboard navigation support (`tabIndex`, `onKeyDown`), making them inaccessible to keyboard and screen reader users. Additionally, icon-only toggle buttons often use `title` for visual tooltips but miss `aria-label` for screen reader access.
**Action:** Always verify that interactive `div` or `span` elements have complete keyboard support (including preventing default scroll behavior on 'Space') and that icon-only buttons include descriptive `aria-label`s.
