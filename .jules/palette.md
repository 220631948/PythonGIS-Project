## 2025-02-20 - Redundant Screen Reader Announcements on Toggle Buttons
**Learning:** Using dynamic `aria-label`s (e.g., "Show layer" / "Hide layer") alongside `aria-expanded` or `aria-pressed` state attributes causes screen readers to redundantly announce state changes (e.g., "Hide layer, button, pressed").
**Action:** Always use static, descriptive `aria-label`s (e.g., "Toggle Zoning Summary", "Sidebar menu") on buttons that convey their state via `aria-pressed` or `aria-expanded`. The state attribute alone is sufficient for the screen reader to communicate the current state to the user.
