## 2024-03-20 - Redundant Screen Reader Announcements on Toggle Buttons
**Learning:** React components that use dynamic `aria-label`s (e.g., `aria-label={isActive ? 'Hide layer' : 'Show layer'}`) alongside native state attributes (like `aria-pressed` or `aria-expanded`) cause redundant and confusing screen reader announcements. Screen readers are optimized to read out the element type, static label, and the native state automatically.
**Action:** Always prefer a static, descriptive `aria-label` combined with `aria-pressed` or `aria-expanded` boolean attributes for toggle buttons. Avoid changing the `aria-label` text based on the component's state.
