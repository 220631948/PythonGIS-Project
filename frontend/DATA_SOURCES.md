# Data Sources 📊

_Last updated: 2026-02-19_

This application relies on the City of Cape Town's Open Data Portal and other public datasets.

| Module | Dataset Name | Source URL | Update Frequency | License |
|--------|--------------|------------|------------------|---------|
| **Services** | Community Facilities (Libraries, Clinics) | [CCT Open Data](https://odp-cct.opendata.arcgis.com/) | Quarterly | CC-BY 4.0 |
| **Transport** | MyCiTi Bus Stops & Routes | [CCT Open Data](https://odp-cct.opendata.arcgis.com/) | Annually | CC-BY 4.0 |
| **Safety** | SAPS Crime Statistics (Aggregated) | [SAPS / StatsSA](https://www.saps.gov.za/) | Annual | Public Domain |
| **Environment** | Biodiversity Network & Wetlands | [CCT Open Data](https://odp-cct.opendata.arcgis.com/) | Bi-Annual | CC-BY 4.0 |
| **Land Use** | Zoning Schemes | [CCT Planning](https://odp-cct.opendata.arcgis.com/) | Ad-hoc | CC-BY 4.0 |
| **Utilities** | Water & Sanitation Infrastructure | [CCT Open Data](https://odp-cct.opendata.arcgis.com/) | Annual | CC-BY 4.0 |
| **Base Maps** | OpenStreetMap / CartoDB | [ISOS Memo / Carto](https://carto.com/) | Continuous | ODbL |
